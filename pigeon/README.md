# GRAND THEFT PIGEON: SHIT HAPPENS

A playable Godot 4.6 3D open-world comedy **prototype**, set in a Bristol-city-centre-inspired environment.

## Gameplay
- Walk, flap, glide, fly, dive, steal chips and launch cartoon pigeon droppings.
- Explore Broadmead, Cabot Circus, Castle Park, the Old City, College Green, Queen Square and the Harbourside.
- Collect five portions of chips, then land five droppings to unlock free roam.
- 35 moving pedestrians, 12 moving vehicles, 24 chip pickups, roofs, buildings, parks and bridges.
- Original generated sound effects. No external asset dependencies.

## Controls
| Action | Keyboard / mouse | Xbox | Touchscreen |
|---|---|---|---|
| Move | WASD | Left stick | Left half drag |
| Camera | Mouse | Right stick | Right half drag |
| Flap / take off | Space | A | A FLAP |
| Dive | Shift | B | B DIVE |
| Poop | F | X or RT | X POOP |
| Steal chips | E | Y | Y CHIPS |
| Map | Tab / M | Select / View | MAP |
| Menu | Esc | Start | MENU |

## Scope and geography
This is a stylised **Bristol-inspired** procedural 3D layout, not an exact GIS reconstruction. Districts are in approximate relative positions; buildings, signs and roads are fictionalised. This project is independent of DROPZONE; no original DROPZONE files are modified.

## Build
Godot 4.6.3, Compatibility renderer, Web export. Open `project.godot` or run the GitHub Actions workflow in `SKB-MECH-MIND`.
